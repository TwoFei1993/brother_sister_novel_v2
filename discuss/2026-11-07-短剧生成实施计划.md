## Phase 2 — 角色/场景 tab + 生图链路

### server
- **T2.1** `services/image.ts`（新，~200 行，**tts.ts 同款模式**）：`generateImage({prompt, aspectRatio, n, subjectRef?})` → secrets `claude.apiKey` → `api.minimaxi.com/v1/image_generation` → 重试退避 → **URL 立即下载转存** `data/works/{id}/duanju/images/{uuid}.png` → 返回本地相对路径。错误码 `IMG_AUTH/IMG_QUOTA/IMG_NET/IMG_TIMEOUT/IMG_UPSTREAM`（key 不进日志）
- **T2.2** `routes/duanju/images.ts`（新）：`POST /api/works/:id/duanju/images`（zod：kind/refId/prompt/refImageId?；写锁内更新对应实体的 sheetImages/images 并 bump updatedAt → stale 联动依据）；`GET /api/works/:id/duanju/files/:name`（authRequired + assertSafeId 扩展文件名白名单 + 流式返回，`Content-Type` 按扩展名）

### client
- **T2.3** `lib/prompts-image.ts`：角色设定图模板（资料第 3 课：三视图/中性站位/无复杂动作/外观锚点全量注入）+ 场景图模板（第 4 课：无人物/空间结构/光影基调/关键道具）+ 画风前缀注入

- **T2.5** `features/duanju/characters/`：`CharactersPane.tsx`（卡片列表+新增/编辑档案）+ `CharacterCard.tsx`（档案表单 + 设定图区：生成/重roll/选主参考图/查看大图）
- **T2.6** `features/duanju/scenes/`：`ScenesPane.tsx` + `SceneCard.tsx`（同构，少参考图概念）
- **T2.7** `api/duanju.ts` 扩展 generateImage

**测试**：image service mock fetch（成功转存/401→IMG_AUTH/超时→IMG_TIMEOUT/下载失败重试）；images 路由鉴权+路径穿越拒绝+updatedAt bump；imageQueue 状态机单测（失败隔离/中止）。
**实测**：真实 key 生成一张角色图（spike 结论落地验证）→ 设为主参考图 → 生成场景图 → 移动端看图。

## Phase 3 — 分镜 tab + 四宫格 + 整集批量 + 导出

### client
- **T3.1** `lib/prompts-storyboard.ts`：AI 拆镜头模板（按集：输出 Shot[] JSON——景别/运镜/动作起终点/站位/台词/声音/四格画面描述）+ 四宫格图 prompt 组装器（角色外观锚点 ∪ 参考图注记 + 场景 spec + 画风 + 四格各自描述 + D7 自检要点注入）+ 视频提示词组装器（第 6 课：独立画板/动作衔接/站位/景别/声音要求，默认无 BGM）
- **T3.2** `lib/stale.ts`：`isStale(shot, project)` —— `builtFrom` 快照 vs script/characters/scenes 的 updatedAt 比对（纯函数）
- **T3.3** `features/duanju/storyboard/`：`StoryboardPane.tsx`（集切换 + AI 拆镜头按钮 + 镜头列表）+ `ShotCard.tsx`（四宫格图/stale 标记/prompt 编辑重roll/复制视频提示词/下载图/打开即梦/上传成品占位）+ `ShotForm.tsx`（镜头字段编辑）+ `BatchBar.tsx`（整集批量：预估张数+费用确认弹窗 → imageQueue 排队 → 逐镜头状态）
- **T3.4** `features/duanju/export/`：`ExportPane.tsx`（整集导出：md 表格预览 + 下载）+ `lib/exportMd.ts`（镜头号/景别/运镜/提示词/声音要求表格生成）

### server
- **T3.5** `routes/duanju/export.ts`（新）：`GET /api/works/:id/duanju/export/:episodeId` → zip 流（archiver：md + 全部四宫格图，文件名 `E{集}-S{镜头}.png`，与回传对应）；**新增依赖 archiver + @types/archiver**

**测试**：四宫格 prompt 组装快照单测（参考图注记/画风注入/stale 传参）；stale 推导单测；exportMd 单测；export 路由 zip 结构冒烟。
**实测**：真实 key 走通「拆镜头 → 单张四宫格 → 编辑 prompt 重roll → 整集批量（先 3 镜头小集验证）→ 导出 zip 解开核对」。

## 风险与备案

| 风险 | 备案 |
| --- | --- |
| 国内端点 image-01 无参考图参数 | 降级：四宫格 prompt 全量注入角色外观锚点（资料第 3 课的文字一致性方案）；数据结构不变 |
| image-01 对「2×2 四格各自动作」遵循度差 | prompt 模板迭代（格间分隔线描述/序号标号）；终极演进 = 切 4 单帧方案，Shot 数据结构已兼容（gridImage → images[4] 仅前端改动） |
| MiniMax key 无生图权限/余额 | IMG_QUOTA 错误码前端人话提示；不阻塞文本链路 |
| 一集 30+ 镜头整图批量烧钱 | BatchBar 预估确认（张数×单价量级）+ 队列可随时中止 |
| webview `<input type=file>` 不弹选择器 | Capacitor Filepicker 插件备案（Phase 4 实测后决定） |
