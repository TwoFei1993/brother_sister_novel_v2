# 人物卡 · 周平安

```
定位：主角
首次出场：第 1 章
当前状态：活跃
```

---

## 一、基础信息

```
姓名：周平安（他爹 1965 年起的名，取"平平安安"）
原身份：★ 红星机械厂 三级钳工，1987 年，二十三岁
       加班到半夜，一脚踏空掉进了归墟
现身份：归墟第九等（末等）弟子，唯一幸存者。轮回系统里查无此人
实际年龄：在归墟待了约二十年，但归墟时间流速不同，他自己也算不清
外貌特征：普通到没有记忆点。
         ★ 这是设定，不是偷懒——全诸天描述他的样貌时众说纷纭，
           因为他实在太平平无奇，所有人都下意识给他脑补了
           一副"深不可测"的样子。
随身物品：一张 1987 年的粮票（没舍得用）、一张红星机械厂出入证、
         一件洗到发白的蓝色工装
实力：归墟末等 ≈ 诸天道祖之上 ★ 他不知道，任何角色不得说破
```

---

## 二、四件套

### ① 缺口

```
生存层：活下去。他真心觉得自己随时会死，所以拼命苟。
情感层：★ 他想回家。
       1987 年那天晚上，他妈说"你早点回来，饭在锅里温着"。
       他没回去。
       他兜里还有那张粮票和一张出入证。
       ——他最怕的不是死，是忘掉他家长什么样。
价值层：搞清楚归墟为什么会毁。
       他以为是自己太弱没护住，就像他没护住那口温着的饭。
```

### ② 反差

```
表面：诸天威胁榜榜首，最恐怖的存在
实际：怕黑，睡觉留灯；被围攻时第一反应是道歉；
     兜里揣着粮票舍不得用，因为"回去还能换二斤面"
不合常理之处：他真心实意觉得自己很弱，
             而且这个判断在他的坐标系里完全正确
```

### ③ 语言指纹 ★★

```
1. 句长：短。经常只有三个字。不用书面语，不用文言，不用感叹号。

2. 口头禅：
   "我打不过。"
   "算了。"
   "有话好好说。"
   "同志，你听我说。"
   "这不合适。"

3. 用词习惯：★ 八十年代工人的词汇系统（本书笑点的主要来源之一）
   - 管副本叫"任务"，管轮回空间叫"单位"，管奖励叫"工分"
   - 管修士叫"同志"，管大能叫"领导"
   - "组织上""按规矩来""影响不好""得走个程序"
   - 不认识的东西一律叫"那玩意儿"
   - 说到钱用"块""毛"，说到重量用"斤"

4. 禁用行为：★★ 违反即人设崩塌
   - 不主动挑衅、不放狠话、不报名号
   - 不占便宜（捡到宝物一定要找失主，找不到就交"组织"）
   - 不浪费东西（剩饭要打包，灵石舍不得花）
   - ★ 不主动攻击任何人 —— 设定层面的硬约束，不只是性格
   - ★ 不承认自己强。别人夸他，他真心以为是阴阳怪气
   - ★ 不许出现"他隐约觉得自己好像有点厉害"这类心理描写
   - 不说脏话（他觉得那不体面）

5. 情绪出口：
   紧张时 —— 鞠躬，然后想给对方递根烟（没烟就递馒头）
   为难时 —— 沉默，然后小声说"要不我走？"
   高兴时 —— "哦"，但会多吃两碗饭
   被夸时 —— 认真道歉，因为他以为对方在挖苦他
   想家时 —— 摸兜里那张粮票，不拿出来，只是摸一下
```

### ④ 梗点

```
主力梗："我打不过。"
  他每次说完这句，接下来必定发生一件让在场所有人
  重新定义"打不过"的事。全书可用 100 次。
  回收频率：每 2~3 章（这是主力梗，可以高频）

配套梗一：鞠躬。
  他一紧张就鞠躬。在诸天规格下，他鞠躬带起的气流
  足以让整条街的人跟着跪下。

配套梗二：递烟。
  他习惯性地想给人递烟缓和气氛。没烟就递馒头、递水、递自己的工装。
  诸天解读：「此乃上古缔约之礼，接了就是同盟。」
  于是有一堆大能因为接过他一个馒头，从此认定自己是他的人。

配套梗三：那张粮票。
  他每次想家就摸一下。全诸天都注意到了这个动作，
  并认定那是一件不可名状的至宝。
  「他每次动用大能之前，都会先触碰怀中之物。」
```

## 三、记忆点动作

```
紧张时先鞠一躬，再说话。
（第 1 章第一次出现。此后每次他鞠躬，读者就知道要出事了——
  出的是别人的事。）
```

## 七、人物弧光

```
起点：只想活下去，苟到任务结束，然后回家
中段：还是只想活下去，但发现越苟麻烦越大
终点：还是没变。他到最后也只是「护」了一下，然后回家吃饭。

★ 本书主角【几乎不成长】——变的是全世界对他的看法。
  这是刻意的反向设计，也是笑点的永动机。
  他唯一的变化是：他终于知道了外面和归墟不一样。
  而他知道之后的第一反应，是问能不能回家。
```

## 九、⚠️ 分寸线

```
★ 八十年代的质朴不许写成"土"或"蠢"。

他不懂修仙，但他懂做人。
他不识字（归墟文字不通用），但他会算账、会看图纸、会磨零件。
他节约，但不吝啬——他会把最后半个馒头分给别人。
他老实，但不好欺负——他只是不还手，不代表他不记得。

读者要能【敬重】他，而不是嘲笑他。
所有的笑点都应该落在"诸天的误解"上，而不是落在他身上。
```
