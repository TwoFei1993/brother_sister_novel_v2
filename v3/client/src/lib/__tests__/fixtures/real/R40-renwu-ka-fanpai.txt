# 人物卡 · 剑无涯

```
定位：第 1 卷阶段反派 → 第一个"被吓疯的大能" → 长期喜剧角色
首次出场：第 1 卷（约第 4 章）
当前状态：活跃
```

---

## 一、基础信息

```
姓名：剑无涯
年龄：三百余岁
外貌特征：右手食指和中指的指腹全是茧，握剑握出来的
身份：剑冢之主，本世界最强剑修
实力：帝君境。在诸天排得上号，在周平安面前……他不知道。
```

---

## 二、四件套

### ① 缺口

```
他一生只求一件事：证明"极致的强"是可以抵达的。
他为此杀过朋友、废过徒弟、砍掉过自己的左臂重练。

★ 所以周平安的存在，会摧毁他人生的全部意义 ——
  一个从不出手、看起来平平无奇的人，随手一挡就断了他的剑。
```

### ② 反差

```
表面：冷酷无情的绝世剑修
实际：极度较真，输了会失眠，会反复回想细节
不合常理之处：他断剑之后没有复仇，而是开始做笔记
```

### ③ 语言指纹

```
1. 句长：短促、命令式，全是断句
2. 口头禅："出剑。" / "再来。" / "……我想不通。"（断剑之后新增）
3. 用词习惯：只谈剑。用剑的术语解释一切，包括吃饭和天气
4. 禁用行为：
   - 不偷袭、不用毒、不挟持人质（他真的有底线，这让他不讨厌）
   - 不认输（但他会说"我想不通"，这是他的认输方式）
   - 不对弱者出剑
5. 情绪出口：
   愤怒时 —— 极度安静，只有握剑的手在动
   困惑时 —— 反复重演那一招，一天几百遍
```

### ④ 梗点

```
梗内容：断剑之后，他开始随身携带那半截断剑，
       逢人就问："你看这断口。你说他是怎么做到的。"
       没人答得上来，他就自己讲两个时辰。
       ★ 全书最好用的"人物梗"之一，每 10 章回收一次。

进阶：后期他成了"周平安学"的权威，出版《论前辈的一次格挡》，
     厚达三千页，全诸天奉为经典。周平安不识字（归墟文字不通用），
     翻了两页说"画得挺好看"。
```

---

## 三、反派专用

```
优势：真的强，本世界天花板，掌握剑冢全部资源和情报网
他的道理：他必须杀光所有参与者才能救剑冢——
         副本奖励是他宗门唯一的活路。他不是为自己。
弱点：★ 他的道心。他一辈子求"强"，
      而周平安的存在让他怀疑这个字本身有没有意义。
嚣张的具体表现：开局当着所有参与者的面，一剑劈了副本的规则石碑，
              说"规则我来定"。
倒台方式：第 34 章。他倾尽全力一剑刺向周平安，
        周平安下意识「护」了一下，剑断了。
        周平安慌忙道歉："对不起对不起，你这剑是不是本来就有裂？我赔。"
        ★ 这句道歉是压死他的最后一根稻草。
        他当场道心崩碎，成为第一个"被吓疯的人"。
```

---

## 四、转化后的定位（第 2 卷起）

```
从反派转为长期喜剧角色 + 主角的第一个"信徒"。

行为模式：
  - 无条件相信周平安的一切行为都有深意
  - 主动替周平安解释他的每一个动作（解释得越离谱越好笑）
  - 会为了"保护前辈的清静"而挡在周平安面前，
    周平安每次都很困惑："你干嘛？"

★ 他是"被吓疯的大能"这个资产池的第一个，也是模板。
  后面每一个新加入的，都要有自己独特的疯法，不许重复。
```

---

## 五、示范对白

```
1. "出剑。"
2. "……我想不通。"
3. "你看这断口。你说他是怎么做到的？"
4.（转化后）"前辈刚才那一步后退，是在给我留活路。你们不懂。"
```
