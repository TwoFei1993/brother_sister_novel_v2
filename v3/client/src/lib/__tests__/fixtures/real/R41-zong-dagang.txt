# 总大纲 ·《我明明超弱，却把诸天吓疯了》

```
预计：80~150 万字，5 卷，约 230 章
结构：每卷 = 一个轮回副本 = 一次"他只想苟，结果吓疯一批人"
```

> 纪律：只有第 1 卷详细展开（见 `05-分卷大纲/第1卷-七天.md`）。
> 第 2 卷以后每卷 6 行，写细了必被推翻。

---

## 一、全书骨架

### 第 1 卷《七天》（第 1~40 章）

```
起点状态：刚被甩进轮回世界，身无分文，不认识路，谁也不认识
本卷目标：躲满七天，活到副本结束
主要对手：剑无涯（剑冢之主，帝君）。为救宗门必须杀光所有参与者。
         强在：本世界天花板 + 全部资源 + 情报网
大爽点：  第 34 章 —— 他下意识「护」了一下，帝君的剑断了。
         然后他慌忙道歉："这剑是不是本来就有裂纹？我赔，我赔得起。"
终点状态：威胁榜第 999 位 / 吓疯 1 人（剑无涯）/ 自我认知："我很弱"
下卷钩子：万象楼把楚昭调去专职跟踪他
```

### 第 2 卷《研究会》（第 41~85 章）

```
起点状态：以为躲过去了，结果成了名单上的人
本卷目标：★ 躲不了了 —— 副本规则是"守城七日"，
         他一躲，城破，所有人死。这是他第一次被规则逼到不能退。
主要对手：★ 不是敌人，是信徒 —— 人族守将裴屠，
         把他当成降世神明，跪着逼他"显灵"。比敌人更折磨。
大爽点：  城破前夜，他只是想睡个安稳觉，用了「藏」，
         结果整座城在妖魔的感知里凭空消失了七天。
终点状态：威胁榜第 87 位 / 吓疯 5 人 / 自我认知："我很弱"
下卷钩子：有人喊出了"归墟"两个字。某个存在因此转过头来。
```

### 第 3 卷《看不见的人》（第 86~135 章）★ 全书最低点

```
起点状态：名声在外，他本人毫不知情，还在琢磨怎么低调
本卷目标：末法都市，灵气断绝，所有人被压制成凡人。
         规则是"找出藏在十万人里的污染源"。他只想找到人然后回家。
主要对手：污染源本身（无形，藏在人群里）+ 他自己能力的边界
大压制：  ★ F04 回收 —— 他护得住所有他看得见的人。
         但有一个他没看见的人死了：给过他一碗面的老太太。
         他第一次真正失去了东西。他的反应不是愤怒，是"我应该早点看见的"。
         他开始睡不着觉。
大爽点：  想起第四诀「守」（可护看不见的人）。
         他以为这是自己"终于练出了一点新东西"。
终点状态：威胁榜第 12 位 / 吓疯 19 人 / 自我认知："我很弱，这次真的差点死"
下卷钩子：他想起归墟毁灭那天，有个东西在看着他
```

### 第 4 卷《归墟》（第 136~190 章）

```
起点状态：睡不好，怕再看不见谁
本卷目标：★ 这一卷的副本，是归墟的残骸。他认得这里每一块砖。
         各方在抢遗迹核心，他只想把师父院子里的东西收拾好。
主要对手：来夺宝的诸天大能 + 食墟的先遣
大爽点：  全场在抢核心，他在扫地。他把师父院里的碎瓦一片片捡起来，
         所有人以为他在布置绝世大阵，没人敢踏进那个院子。
         食墟先遣降临时，他为了不让人踩坏院子，「护」了一下。
揭示：    F03（归墟为什么毁）、F02（记忆的真相）、F05 铺垫
终点状态：威胁榜第 3 位 / 吓疯 60+ 人 / 自我认知："我很弱"
下卷钩子：食墟本体来了
```

### 第 5 卷《你太弱了，在这里》（第 191~230 章）

```
起点状态：全诸天最恐怖的人，兜里还揣着那张粮票
本卷目标：活下来。顺便把大家也带活。
主要对手：食墟（无形体，靠吞噬世界规则存活）
决战机制：★ 食墟无法吞噬【不被理解之物】。
         全诸天对周平安的误会，汇聚成它无法解析的壳。
         周平安全程以为大家是在陪他一起躲，还说"人这么多，会不会太挤了"。
高潮：    他用出人生第一个攻击招式。用完自己吓哭了。
         F01 回收 —— 师父遗言完整版：「你太弱了……在这里。」
终点：    威胁榜榜首 / 全诸天 / 自我认知："……哦。外面和归墟不一样啊。"
         然后他问："那我现在能回家了吗？"
结局：    1987 年的傍晚。他推开门。他妈说"回来啦？洗手吃饭。"
```

## 二、卷与卷的递进检查

| | 对手强度 | 副本规则 | 误会类型（不许重复） | 主角的处境 |
|---|---|---|---|---|
| 1卷 | 帝君 | 互杀 | 以为他在装、深不可测 | 能躲 |
| 2卷 | 妖潮 + 信徒 | 守城生存 | 以为他是神，逼他显灵 | ★ 躲不了 |
| 3卷 | 无形污染源 | 解谜找人 | 以为他在考验大家 | ★ 躲了也没用 |
| 4卷 | 诸天群雄 + 食墟先遣 | 夺宝 | 以为他在布局 | ★ 不想躲了 |
| 5卷 | 食墟 | 无规则 | 全诸天集体误会 = 武器 | ★ 大家来陪他躲 |

> ★ 这条线是全书的隐藏主线：**从"能躲"到"躲不了"到"不用躲"。**
> 主角本人几乎不变，变的是他和世界的关系。

## 五、"被吓疯的大能"资产池

> 本书最重要的可积累资产。每一个都是一个梗点，到结局全部变成他的后盾。

```
铁律：每个新加入的，必须有【自己独特的疯法】，不许重复。

1 号 · 剑无涯（1卷）—— 逢人就掏出断剑问"你看这断口"
2 号 · 裴屠（2卷）  —— 给他立了生祠，每天上香汇报工作
3~5 号（2卷）      —— 各自的疯法待定，排细纲时定
...
结局：全诸天。他们的误会汇成挡住食墟的壳。
```

## 七、⚠️ 全书四条死线

```
1. 周平安永远不许主动攻击（第5卷高潮那一次除外，且用完他吓哭了）
2. 周平安永远不许意识到自己强（前四卷）
3. 所有"厉害"必须由旁人反应演出来，主角视角里一切平平无奇
4. 八十年代的质朴不许写成"土"或"蠢"。
   笑点落在诸天的误解上，不落在他身上。读者要敬重他。
```
