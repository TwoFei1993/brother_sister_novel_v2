# 世界观设定 ·《我明明超弱，却把诸天吓疯了》

> 只写会影响剧情的部分。**本书的世界观核心就是一件事：两把尺子。**

---

## ★ 一、两把尺子（全书最重要的设定）

这本书的所有笑点、爽点和误会，都来自**两套互不兼容的力量刻度**。

### 诸天万界的尺子（外面的世界用这把）

```
凡境 → 真人 → 地仙 → 天君 → 帝君 → 道祖

道祖：一界之巅，万年出一个，一言可定一界生死。
     全诸天已知的道祖，不超过二十位。
```

### 归墟的尺子（周平安用这把）

```
归墟弟子分九等，一等最高，九等最低。
周平安是【第九等】，末等，倒数第一。这是客观事实。

★ 换算关系（全书只有读者知道）：
   归墟第九等 ≈ 诸天的道祖之上

   也就是说：周平安眼里"我是个连门都没入的废物"，
            在外面是"超出已知上限的存在"。
```

### ★ 第三个变量：笨功夫

```
天赋末等，不代表练得差。

周平安是 1987 年红星机械厂的三级钳工。
他把《苟命三诀》当成【手艺】在练——像在车间磨一个零件那样，
一个动作八百遍，练二十年，不问为什么，也不觉得苦。

于是：天赋末等的功法，被他练成了诸天没人见过的样子。

他自己的看法是：「这不就是熟练工嘛。谁练二十年都这样。」

★ 这一层同时解决两个问题：
  ① 为什么"天赋倒数第一"能强成这样
  ② 为什么他真心觉得这没什么了不起
```

### 为什么这个误会永远不会破

```
1. 归墟已经毁了，没有第二个归墟人能告诉他换算关系
2. 他从不主动出手，所以从没有过一次公平的实力测试
3. 每次有人说"前辈您太强了"，他都认为对方在客气、在下套、或在嘲讽
4. 他的参照系里，"道祖"这个词根本不存在——他没听说过，
   听说了也只会以为是外面对"入门弟子"的称呼
5. ★ 他把自己的水平归因于"练得久"，而不是"天赋高"——
   而这个归因，在他的坐标系里也是对的
```

## 二、归墟

```
性质：诸天万界的顶点，一个已经毁灭的上位世界
状态：已被"食墟"吞噬，只剩周平安一人
特点：归墟人自己不认为自己强——他们的日常标准就是那样，
     就像鱼不觉得水湿

周平安怎么进去的：
  1987 年某个夏夜，红星机械厂三级钳工周平安加班到半夜，
  下班路上一脚踏空，掉进了归墟。
  ★ 具体原理全书不解释（第5卷才碰）。他自己的理解是"掉沟里了"。

关于师父：
  归墟第一等，周平安的授业恩师。
  收他的理由：「这孩子肯下笨功夫。」
  临死前把周平安送出归墟，留下遗言：
  「你太弱了……（巨响）……出去千万别出手，苟住。」
  ★ 被盖住的三个字是「在这里」（F01，第5卷回收）
```

## 二·五、★ 八十年代（他真正的故乡）

```
只需要保留这些，不写完整年代设定：

红星机械厂：他上班的地方，三级钳工，八级工制里的中下等
家：厂里的家属院，煤球炉，葱花味的楼道
他妈：最后一句话是"你早点回来，饭在锅里温着"
随身三样：1987 年的粮票、车间出入证、洗到发白的蓝工装

★ 作用：
  ① 提供他全部的价值观和词汇系统（见 立项书·八十年代梗库）
  ② 提供全书唯一的温暖锚点——这本搞笑书的底
  ③ 提供结局的落点（他要回去吃那口温着的饭）

⚠️ 不写：八十年代的政治、社会事件、具体地名。
   只保留"一个普通工人家庭的傍晚"这个质感。
```

## 三、轮回世界（无限流骨架）

```
性质：诸天之间的夹缝空间，会不定期把各界生灵拉进来
参与者：被拉进来的各界修士，称"轮回者"
规则：每个副本有独立规则，通关可获奖励并返回原界
     副本失败 = 死

★ 周平安是被归墟崩塌的余波"甩"进来的，不是被选中的。
  他没有轮回者身份，系统里查无此人 —— 这是第 1 卷所有误会的起点：
  一个查不到来历、查不到实力、查不到目的的存在。
```

### 副本设计规范（每卷一个）

```
每卷 = 一个轮回世界 = 30~45 章

每个副本必须换：
  世界类型：修真界 / 妖魔界 / 末法都市 / 剑冢 / 神战遗迹
  副本规则：互杀 / 生存 / 解谜 / 守城 / 逃亡
  误会类型：不能每次都是"以为他在装"

固定节拍：
  进入 → 只想苟 → 被迫卷入 → 一次被动出手 →
  本地最强者怀疑人生 → 误会滚雪球 → 吓疯 boss + 榜单跃迁 → 下一个
```

## 四、诸天威胁榜

```
性质：由各界大能联合维护的名单，标注"绝对不能招惹的存在"
用途：本书的主角成长刻度 + 长期笑点

维护者：万象楼（诸天最大的情报机构）
更新：每次有大能上报"遭遇"后重新评定

★ 笑点设定：周平安见过这张榜三次，每次都以为是某种活动排行榜。
  他还认真研究过"怎么才能不上榜"——
  而他为了不上榜做的每一次躲避，都被解读成更高深的布局，
  名次反而一路飙升。
```

|---|---|---|---|---|
| 万象楼 | 楼主（未露面） | 情报网覆盖诸天 | 榜单维护者，最早盯上他 | 太信自己的情报 |

## 六、"误会"的生成规则 ★

> 这是本书的核心工艺。每一次误会都要走完这三步，不能凭空捏造。

```
第一步：周平安做一个【完全平凡】的动作，动机必须是"苟"
       例：他怕被打，后退了一步

第二步：在诸天的规格下，这个动作产生【超规格的物理结果】
       例：那一步跨了三千里，原地留下一道残影

第三步：旁人用【他们自己的知识体系】去解释，得出恐怖结论
       例："他一步跨越三千里，还特意留了个残影嘲讽我——
            他在告诉我，追是追不上的。"

★ 铁律：三步的因果链必须成立。
  不许出现"旁人无端脑补"——每个误会都必须有一个真实发生的物理事件当锚。
  这是本书区别于同类烂书的关键。
```

### 误会解读的写法

```
✓ 正确：先写周平安视角（平平无奇），再切旁人视角（惊天动地）
       两者对同一件事，必须能对得上细节

✗ 错误：主角视角里也写得很帅
✗ 错误：旁人的解读脱离了实际发生的事
```

## 七、不写的东西

```
✗ 诸天的完整地理和历史
✗ 归墟的详细文明设定（只保留"两把尺子"必需的部分）
✗ 轮回空间的来历（第5卷之前不碰）
✗ 用不到的门派、种族、功法
```
