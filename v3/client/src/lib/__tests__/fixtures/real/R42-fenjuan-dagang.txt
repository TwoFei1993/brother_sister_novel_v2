# 分卷大纲 · 第 1 卷《七天》

```
章节范围：第 1 ~ 40 章
预计字数：约 10 万字
副本世界：剑冢所在的修真世界
副本规则：七天内，杀死其他所有参与者。最后活着的人获得奖励。
```

> **本卷的任务只有一个：让读者在第 3 章就爱上"三重认知差"这个乐趣。**
> 第 1 卷决定这本书的生死，值得反复重写。

---

## 1. 起点状态

```
主角实力：归墟第九等（末等）≈ 诸天道祖之上 ★ 他不知道
主角财富：三百块钱（1987 年的）、一张粮票、一张出入证
主角身份：无。轮回系统里查无此人。
所在地：副本入口，一片乱石坡
遗留问题：归墟刚毁，师父刚死。他还没缓过来。
心态：只想活到任务结束，然后想办法回家
```

## 2. 本卷目标

```
主线：躲满七天，活到副本结束。
支线：把捡到的东西还给失主（他认真的）。
     ★ 这条"支线"会成为他暴露的主要原因 —— 他为了还东西，
       一次次主动出现在所有人面前。
```

## 3. 主要对手 · 剑无涯

```
是谁：剑冢之主，帝君境，本世界最强剑修
强在哪：本世界天花板 + 剑冢全部资源 + 覆盖全副本的情报网
凭什么压制：他能锁定任何人的位置，能调动几百号人清场。
          周平安躲得再好，架不住对方把整座山削平。
他的道理：★ 他不是坏人。副本奖励是剑冢唯一的活路，
        他必须杀光所有参与者。他为的是宗门几千条命。
他的弱点：★ 道心。他一生求"极致的强"，
        而周平安的存在会让他怀疑这个字有没有意义。
倒台方式与章节：第 34 章。他倾尽全力一剑刺来，
              周平安下意识「护」了一下，剑断了。
              周平安慌忙道歉，还要赔钱。他当场道心崩碎。
```

## 4. 本卷大爽点

```
位置：第 34 章
是什么：帝君全力一剑，被一个"路过的老实人"随手挡断
爽点类型：被动打脸 + 三重认知差 + 反向装逼被认出
前置压制：第 24~29 章（他失去藏身处，来福被抓当诱饵，被逼现身）
观众是谁：★ 剑冢全部弟子 + 剩下的所有轮回者 + 躲在暗处记录的楚昭
量化结果：帝君的本命剑断了。剑无涯跪坐在地上，三次没站起来。
         副本剩余参与者当场全部放弃战斗。
         周平安掏出三百块钱要赔剑。
```

## 5. 本卷新增

```
新地图：剑冢世界（乱石坡 → 山下小镇 → 剑冢山门）
新能力：无（三诀在第 1 章末尾全部亮相，本卷不解锁新东西）
新人物：★ 只有 3 个有名有姓的
  - 老麻子（第 2 章）：低阶轮回者，猥琐但没坏心。
                     喜剧型 + 试金石型 + ★ 误会的第一个放大器
  - 楚昭（第 6 章）：万象楼情报员，读者代言人
  - 剑无涯（第 4 章远景 / 第 11 章正面）：本卷对手
新设定：轮回世界规则、诸天力量阶梯、诸天威胁榜（卷末才出现）
新梗点：来福（那条狗）、"我打不过"、鞠躬、递馒头、粮票
```

## 6. 情绪曲线

```
第 1~3 章   黄金三章：掉进来 → 规则宣布 → 第一次被动出手   [快节奏↑]
第 4~10 章  他开始躲。越躲越显眼。连续小爽              [持续↑]
第 11~16 章 剑无涯盯上他，开始清场                      [压制↓]
第 17~23 章 楚昭登场记录，误会滚雪球，他成了所有人的焦点   [小释放↑]
第 24~29 章 藏身处没了，来福被抓当诱饵                  [大压制↓↓]
第 30~34 章 被逼现身 → 断剑                            [大释放↑↑]
第 35~40 章 剑无涯崩溃、研究会雏形、榜单 999、下卷钩子    [收束+钩子]
```

> ✓ 压制段最长 6 章（24~29），且期间有小爽点（第 26 章他把捡到的剑还给剑冢弟子）
> ✓ 大爽点在第 34 章，符合"每卷末大释放"

## 8. 终点状态

```
实力：无变化（他没变强，他本来就那样）★ 这是本书的特色
财富：三百块钱 + 一张粮票（一分没花，还多了几个馒头）
地位：诸天威胁榜 第 999 位（备注：疑似伪装成凡人的古神）
身份：仍然查无此人。但已经有一整个机构在研究他
吓疯的大能：1 人（剑无涯）
自我认知：★ "我很弱"（不许变）
```

## 9. 下卷钩子

```
第 40 章：万象楼把楚昭调去专职跟踪周平安。
        楚昭接到的任务书上写着：
        「目标代号：归墟。等级：不可接触。备注：不要与之对视。」
        楚昭抬头看向不远处 —— 周平安正蹲在路边喂狗，
        嘴里念叨着"慢点吃，没人跟你抢"。
```

## 附：本卷章节事件流（排细纲前的骨架）

> 一个事件 = 1~3 章。排细纲时按"一章一事"拆开。

```
【黄金三章】
1. 1987 年那晚（≤150字回闪）→ 掉进副本 → 规则石碑宣布"七天内杀光所有人"
   → 他第一反应是找地方躲 → 路上捡到一条断腿的流浪狗，给它包扎，起名来福
   → 章末：有人冲他动手，他下意识「退」了一步。
2. 那一步跨了三千里。他自己吓一跳，以为是自己"练岔了"。
   → 遇到老麻子。老麻子亲眼目睹，当场跪了。周平安扶他起来，递了个馒头。
   → 老麻子从此认定这是"缔约"，成了他第一个"手下"（他不知道）
3. 老麻子把消息传出去。三个轮回者来试探。
   周平安说"有话好好说"，他们不听，动了手。
   他「护」了一下 —— 三个人的兵器一起断了。
   他慌忙道歉，要赔。★ 第一次被动打脸完成。

【躲，越躲越显眼】
4-5.  他躲进山下小镇，想安静待七天。远景第一次出现剑无涯（劈了规则石碑）。
      他打听怎么才能"不参加任务"，被当成挑衅。
6-7.  楚昭登场。她奉命调查这个"查无此人"的存在，开始记录。
      【记录 No.1】目标今日购买馒头两个，付钱时数了三遍。
8-10. 他为了把捡到的一柄剑还给失主，主动去了剑冢山门。
      门口弟子拦他，他鞠了个躬 —— 气流把整条街的人掀跪了。
      他吓坏了，连连道歉，跑了。★ 全副本轰动。

【剑无涯盯上他】
11-13. 剑无涯正面登场。他要杀光所有人，必须先弄清这个变数是什么。
       他派人试探，试探的人一个没回来（其实是被周平安请去吃了顿饭，
       吃完不好意思动手，自己跑了）。
14-16. 剑无涯开始清场，削平了三座山头。周平安的藏身处一个个没了。
       他很苦恼：他只是想找个地方待着。

【误会滚雪球】
17-19. 他躲进一个山洞，用了「藏」。整个副本的探查手段同时失灵了一天一夜。
       所有人以为副本出了故障。★ 第 19 章：他想家，摸了一下粮票。
       楚昭在暗处记录：「目标反复触碰怀中一物，疑为归墟本源。」
20-23. 老麻子已经在外面把他吹成了神。剩下的轮回者开始来投靠他。
       他很为难，说"我这儿也不管饭啊"。
       ★ 第 22 章：一次小事故 —— 有人从他背后的方向掉下悬崖，
         他没看见，没接住。人没死，但他愣了很久。（F04 埋）

【大压制】
24-26. 剑无涯锁定了他的位置。周平安决定换地方，但发现来福不见了。
       ★ 第 26 章小爽：他去找狗的路上，把捡到的剑还给了一个剑冢弟子。
         那弟子后来成了他的证人。
27-29. 来福被剑无涯当诱饵拴在剑冢山门口。
       周平安站在山下看了很久。
       ★ 他不是愤怒，他是难过 —— "它腿刚好，不能这么拴着。"
       他走上去了。这是全书第一次他主动往危险里走。

【断剑】
30-33. 他上山门。一路上没还手，被打了三十七次，衣服破了，人没事。
       他每挨一下就说一句"同志，有话好好说"。
       剑无涯在山门等他。全副本的人都在看。
34.    ★ 大爽点。剑无涯倾尽全力一剑刺来。周平安下意识「护」了一下。
       剑断了。
       周平安慌忙道歉："对不起对不起，你这剑是不是本来就有裂纹？
       我赔，我赔得起。"
       他掏出三百块钱。
       剑无涯跪坐在地上，三次没站起来。

【收束】
35-37. 剑无涯道心崩碎。他没有复仇，他开始做笔记。
       周平安解开来福，抱着狗下山。全场没人敢拦。
       剩下的参与者集体放弃战斗 —— 副本第一次出现"无人死亡"的通关。
38-39. ★ F06 回收：系统结算时查不到周平安的身份。
       楚昭据此推断出"他不是被选中的，是自己掉进来的"，
       并得出一个恐怖结论：能自己走进轮回世界的，只有传说中的……
40.    诸天威胁榜更新：第 999 位。
       万象楼把楚昭调去专职跟踪。任务书：「代号归墟，不可接触，不要对视。」
       楚昭抬头 —— 周平安正蹲在路边喂狗："慢点吃，没人跟你抢。"
```

```
【黄金三章】

[ ] 第 3 章有更大的冲突 + 悬念 ✓
[ ] 前 500 字：规则冲突 + 主角劣势 + ≥3 句对话，禁止年代生活展开

【节奏】
[ ] 前 10 章每章一个明确爽点 ✓
[ ] 压制段最长 6 章，期间有小爽点 ✓
[ ] 爽点类型 ≥ 5 种（被动打脸 / 认知差 / 年代认知差 / 反向装逼 / 信徒增长）✓

【人物】

[ ] 剑无涯有自己的道理（救宗门），不是纯反派 ✓
[ ] 主角全卷没有主动攻击过一次 ✓
[ ] 主角全卷自我认知没有变化 ✓

【伏笔】
[ ] 本卷埋 8 条、强化 1 条、回收 1 条
[ ] 卷末未回收总数：9 / 12 ✓
[ ] ⚠️ 本卷不得再新增主线伏笔
```
