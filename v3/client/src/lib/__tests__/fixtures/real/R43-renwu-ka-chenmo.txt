## 二、四件套

### ① 缺口
```
生存层：这个月房租 1800，卡里 300
情感层：妹妹陈星换肾 47 万 + 合适肾源，医生给的期限"明年三月前"
价值层：查清三年前那场把父母卷进去的"意外"
```

### ② 反差
```
表面：话少、脾气硬、看着挺冷
实际：算得比谁都清，护短护到不讲理
不合常理之处：手上已经有人命了，但看见路边被撞的猫会停下来送宠物医院；
             王胖子把签子扔地上，他会弯腰捡起来扔进桶里
```

### ③ 语言指纹 ★★

```
1. 句长偏好：极短。经常只回两个字。很少说完整的复句。
2. 口头禅："嗯" / "没有" / "走吧"
3. 用词习惯：不用形容词，只说事实和数字。不用网络词。
             被问到麻烦事时用"没事"打发过去。
4. 禁用行为：★★
   - 不解释自己的处境（不说"我妹妹病了所以我很难"）
   - 不求人（宁可自己扛，绝不开口借钱）
   - 不说狠话（他要动手就直接动手，不预告）
   - 不在妹妹面前说钱的事
   - 不哭，不摔东西，不骂人
   - 说谎时会说"没有"，且眼睛往左看 ← 这是他唯一的破绽（F07）
5. 情绪出口：
   愤怒时 —— 变得更安静，手上的动作变慢
   难受时 —— 找事做（洗碗、擦车、剥橘子）
   高兴时 —— 也只是"嗯"一声，但会多说一句无关的话
```

### ④ 梗点
```
梗内容："我没事" —— 他每次说完"我没事"，接下来必定出事，
       或者他必定去干一件很不"没事"的事。全书可反复用。
回收频率：每 8~15 章一次
已回收：第 1 章（对妹妹说"没有"，转头去点了那颗星）
```

## 四、主角专用

### 马甲清单
```
本书不走马甲流。陈默没有隐藏身份——他的"底牌"是能力，不是过去。
★ 这意味着爽点必须靠「信息碾压」和「当众打脸」撑，不能指望身份揭露。
   排细纲时要特别注意爽点类型的多样性。
```

## 七、示范对白（写正文时对照语气）

```
1. "汤没洒。"
2. "因为知道了也改不了。"
3. "没有。"（他撒谎的时候只会说这两个字）
```

> 写完一段陈默的对话后，回来对照这三句。
> 如果他说了超过 15 个字的完整长句，且是在解释自己——**写崩了，重写。**
