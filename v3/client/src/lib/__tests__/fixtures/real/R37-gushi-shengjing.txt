# 故事圣经 ·《我明明超弱，却把诸天吓疯了》

---

## 1. 一句话故事

```
1987 年红星机械厂的钳工周平安，加班到半夜一脚踏空掉进上位世界"归墟"，
被师父收下练了二十年只有三招的《苟命三诀》，天赋末等，
归墟被"食墟"吞噬后他流落诸天轮回世界，
带着师父遗言"你太弱了，出去千万别出手"和一张 1987 年的粮票，
为了活下去、回家，
与整个诸天对他的滔天误会（以及真正在追他的食墟）纠缠，
最终在全诸天都认定他是最大威胁时，用这一身误会挡住了食墟，
然后回到 1987 年那个傍晚，锅里的饭还温着。
```

## 2. 一句话卖点

```
师父说他天赋末等，临死前叮嘱"你太弱了，出去别出手"——他信了一百年。
可归墟的末等，是诸天万界的天花板。
而他兜里，还揣着一张没用完的粮票。
```

---

## 3. 三层冲突

```
远景（全书）：吃掉归墟的"食墟"顺着他的踪迹追来，
             而全诸天都以为周平安本人才是那个威胁。
中景（第1卷）：在第一个轮回世界活到副本结束。
近景（前3章）：副本规则是"七天内杀死其他所有参与者"。
             他决定：躲七天。顺便把捡到的东西还给失主。
```

---

## 4. 结局 ★ 已锁定

### 食墟怎么倒的

```
食墟靠吞噬"世界的规则"存活，但它无法吞噬【不被理解之物】。
而周平安是全诸天最被误解的存在——没有任何一个人真正理解他。

最后一战，所有被他吓疯的大能自愿站到他身后，
他们对他的荒谬误会，汇聚成一层食墟无法解析、因而无法吞噬的壳。

周平安全程以为大家是在陪他一起躲。
他还挺不好意思，说"人这么多，会不会太挤了"。

★ 全书最大的伏笔回收：他一辈子被误会，最后这些误会救了所有人。
```

### 主角的「缺口」怎么被填上

```
他终于想起了师父的脸，和那句遗言的完整版本：

    「你太弱了……在这里。」

最后三个字被归墟崩塌的巨响盖住了。他一百年没听见。
师父从头到尾没骗过他——在归墟，他的天赋确实是末等。
师父只是来不及告诉他：外面用的不是这把尺子。

而他想起来的那一刻，师父正在哭。

★ 周平安听完的反应不是狂喜，是愣了很久，然后"哦"了一声。
  接着他小声问了一句：
  "那……我现在能回家了吗？"
```

### 最后一个画面

```
1987 年的傍晚，红星机械厂家属院。

他推开门。楼道里有煤球和葱花的味道。
厨房里他妈头也没抬："回来啦？洗手吃饭。饭在锅里温着呢。"

他"嗯"了一声。
把那张粮票放回抽屉里。

——

尾声（另一个世界）：
剑无涯捧着三千页的《论前辈的一次格挡》，翻到最后一页，久久不语。
楚昭合上记事簿，在封面上写下最后一行：
「结论：查无此人。」

诸天威胁榜榜首那一栏，永远空着一个名字。
没有人敢删。
```

## 5. 金手指

```
名称：归墟道躯 +《苟命三诀》（练了二十年）

能做什么：
  归墟道躯 —— 防御 / 恢复 / 感知均为诸天规格（他以为这叫"身体好"）
  藏 —— 隐匿。诸天所有探查手段同时失灵。
  退 —— 后退一步千里，必留残影（他以为残影是没练到家）
  护 —— 格挡。接得住任何攻击，只能防，不能反弹。

不能做什么：★
  1. 不会任何攻击招式，一个都不会
  2. 不能主动开启战斗——三诀全为被动触发
  3. 做不出"看起来厉害"的动作，出手朴实无华
  4. 护不了自己【看不见】的人 ← 第3卷真正的危机

代价：
  每次动用归墟之力，遗忘一点归墟往事。
  ★ 他最怕的是——照这么下去，他会忘掉 1987 年他家的样子。
    他已经想不起他妈那天穿的什么了。

成长路径（他以为在变强，其实是在想起来）：
  一：只会三诀
  二：想起第四诀「守」（可护看不见的人）—— 第3卷
  三：想起归墟毁灭的真相 —— 第4卷
  四：想起师父遗言的完整版本 —— 第5卷
  五：用出人生第一个攻击招式，用完自己吓哭了 —— 全书高潮
```

|---|---|---|---|---|
| 起点 | 未上榜 | 0 | "我很弱" | 流落轮回世界 |
| 1卷末 | 第 999 位 | 1（剑无涯） | "我很弱" | 断了剑无涯的剑 |
| 2卷末 | 第 87 位 | 5 | "我很弱" | 周平安研究会成立 |
| 3卷末 | 第 12 位 | 19 | "我很弱，这次真的差点死" | 护不了看不见的人 |
| 4卷末 | 第 3 位 | 60+ | "我很弱" | 想起归墟真相 |

> ★ "自我认知"这一列**前四卷不许变**。这是本书的命。

## 8. 爽点节奏总表

```
主打爽点（按优先级）：
  1. 三重认知差 ★ 读者知道 / 旁人误解 / 他自己不知道
  2. 年代认知差 ★ 八十年代价值观 vs 修仙世界解读
  3. 被动打脸
  4. 反向装逼被认出
  5. 信徒增长（被吓疯的大能数量）

密度：
  1~10章 ：每章 1 个明确爽点，第 3 章前完成第一次"被动打脸"
  11~50章：每章 1 小爽，每 5 章吓疯一个大能
  每卷末 ：超大爽——榜单跃迁 + 集体误会大爆发
```

## 9. 调性与风格

```
调性：轻松搞笑（梗密度高），★ 底色温暖
梗密度：每章 3~5 个笑点。主力是「认知差梗」「年代梗」「人物梗」
感情线：≤5%，第3卷再定
叙事视角：★ 全书固定周平安视角。
         只有"误会解读"段落可短暂切旁人视角，且必须明显分隔。
单章字数：2000~3000
```

## 10. 核心看点

```
1. 一个动作能抖三层包袱——结构性优势，别的书给不了
2. 他越苟，误会越大；误会越大，他越要苟。这个循环可以永动
3. "被吓疯的大能"是可积累、可量化、可回收的资产，
   每个都是一个梗点，到结局全部变成他的后盾
4. ★ 八十年代的质朴给这本搞笑书垫了一个温暖的底：
   全诸天最恐怖的存在，兜里揣着一张粮票，只想回家吃口热饭
5. 结局把"被误解"这件憋屈事，翻转成救世的力量
```

---

## ⚠️ 四条死线（每章写作前默念）

```
1. 周平安永远不许主动攻击。一次都不行。
2. 周平安永远不许意识到自己强。任何"他隐约觉得自己有点厉害"
   的心理描写都是崩人设，直接删。
3. 所有"厉害"必须由旁人反应演出来。主角视角里一切平平无奇。
4. ★ 八十年代的质朴不许写成"土"或"蠢"。
   他是稳重、体面、有原则的人。他不懂修仙，但他懂做人。
   读者要能敬重他，而不是嘲笑他。
```
