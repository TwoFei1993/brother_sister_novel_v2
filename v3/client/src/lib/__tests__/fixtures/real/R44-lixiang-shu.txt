# 立项书 ·《我的差评能要人命》

> ⚠️ 这是**示例项目**，用于展示各文件填满后的样子。不是要写的真书。

## 一句话卖点
外卖员发现自己给出的每一个差评，都会精准吸走对方一年寿命——而他妹妹的命，还差七年。

## 赛道
```
主赛道：都市异能
子标签：暗黑爽文 / 能力有代价 / 逆袭 / 道德困境
调性：冷硬 + 黑色幽默（每章 1~2 个笑点，靠围观群众和搭档抖）
```

## 主角
```
姓名：陈默，24岁
起点：跑外卖三年，租在城中村六楼，电表箱上贴着第三张催缴单。
      妹妹陈星，19岁，尿毒症，靠透析吊着，医生说撑不过一年。
性格：话少、脾气硬、算得清、护短到不讲理
反差：手上有人命，但看见路边被撞的猫会停下来送宠物医院
缺口：
  生存层：这个月房租 1800，卡里 300
  情感层：妹妹的换肾费用 47 万 + 合适的肾源，医生给的期限是"明年三月前"
  价值层：查清三年前那场把父母卷进去的"意外"
```

## 金手指
```
名称：差评（无正式名字，主角自己叫它"那玩意儿"）
能做什么：给某人打出一星差评并附真实理由，可吸走对方 1 年寿命，
         转移到主角指定的一个人身上（含他自己）。
不能做什么：★
  1. 理由必须是主角真心认为的，敷衍的差评不生效
  2. 同一个人一生只能被差评一次
  3. 必须是当面接触过、有过真实服务往来的人
  4. 不能吸走对方最后一年（对方只剩一年时，能力无效）
代价：每转移 1 年，主角会随机继承对方的一段记忆，无法选择，无法拒绝。
     记忆会在深夜自动播放，像做梦，但很真。
成长路径：
  阶段一：单次一年 →
  阶段二：发现"连续差评同一批人"可以叠加 →
  阶段三：发现能反向操作（五星好评可以给人续命，但要从自己身上扣）→
  阶段四：真相——这套规则是谁定的
```

## 核心冲突
```
远景：三年前那场"意外"背后的组织，和这套规则的来源
中景（第1卷）：凑够 47 万手术费，同时找到肾源
近景（前3章）：今晚之前要交 1800 房租，妹妹的透析费还差 900
```

## 主要对手
```
第1卷对手：孙博远 —— 私立肾病医院的院长，倒卖肾源，
          把陈星的排队顺位一次次往后压，因为她付不起"加急费"。
          优势：资源、信息、合法身份。弱点：他儿子。
终极反派：暂定"规则的另一个持有者"，用五星好评在给自己续命，已活了很久。
```

## 爽点配置
```
主打（按优先级）：信息碾压 → 当众打脸 → 财富暴涨 → 马甲揭露
节奏：前10章每章1爽；第3章前完成第一次大打脸
第1章末：能力第一次显形（客户当场吐血）
第2章：第一次主动使用 + 第一次打脸
第3章：更大的对手（孙博远）出场 + 大悬念（记忆碎片里有他父亲）
```

## 篇幅与调性
```
预计：90 万字，5 卷
调性：冷硬正剧 + 黑色幽默
感情线：≤10%，单女主（医院护士，姜宁），慢热
单章：2000~3000 字
```
