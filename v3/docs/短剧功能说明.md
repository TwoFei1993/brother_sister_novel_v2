> 成本优化决策：`discuss/2026-11-09-短剧成本优化方案.md`（分帧模式替代 D7 整图）
> 实施计划：`discuss/2026-11-07-短剧生成实施计划.md`

## 功能总览

第三种作品模式 `duanju`（与互动小说/对话写作并列，创建后锁定）。工作台五 tab：
**剧本 → 角色 → 场景 → 分镜 → 出图/导出**（剧本定稿前下游锁定）。

| 环节 | 实现 |
| --- | --- |
| 剧本 | 三来源（AI 生成/粘贴/手写）→ AI 拆解审核卡（六卡逐项确认 + 违审替换）→ 定稿门 |
| 角色 | AI 从剧本提取档案 → MiniMax image-01 设定图（3:4）→ 主参考图选定 |
| 场景 | 档案 + 概念图（16:9 无人物） |
| 分镜 | AI 按集拆镜头 → **分帧生成**（每镜头 4 帧 F1-F4，帧描述可编辑，单帧重roll 只花 1/4）+ 站位快览（左中右零成本预检）→ 整集批量（帧级任务 + 预估确认 + 并发 2 队列） |
| 出图/导出 | 镜头卡即梦四件套（复制提示词/2×2 拼图下载/打开即梦/上传成品视频）；**成本仪表盘**（记账张数/重roll 浪费/盘面估算）；整集 zip（镜头表 md + E-S(-F) 命名分镜图）；整集连播检查衔接 |

## 成本优化核心（2026-11-09）

- **分帧替代整图四宫格**：整图模式修一格 = 整张重roll（四格全部重新抽卡，"四格同时满意"概率陷阱）。分帧后单帧独立重roll，同满意标准下期望花费约**减半**，单次修补确定性 1 张钱。
- **兼容**：升级前的 `gridImage` 旧整图镜头正常展示/导出（批量时跳过，可在镜头卡手动补帧）。
- **记账**：`project.spendLog[]`（server 持锁追加，cap 5000，客户端只读）——升级后每次生图入账，仪表盘按 0.2 元/张估算。

## 部署要点

- **无新增 env / 无 secrets 结构改动**：生图与 LLM/TTS 复用 `secrets.json` 的 `claude.apiKey`（MiniMax 平台 key，Phase 0 spike 实证）。
- **新增依赖**：server 侧 `archiver`（zip 导出）。
- **数据布局**：`data/works/<id>/duanju/`（project.json + images/ + videos/）；与小说消息流完全隔离。
- **API**：`GET|PATCH /api/works/:id/duanju`、`POST .../duanju/images`（kind=character|scene|shot|**frame**+frameIndex）、`POST .../duanju/videos`（multer ≤100MB）、`GET .../duanju/files/:name`（鉴权流，mp4 支持 Range）、`GET .../duanju/export/:episodeId`（zip）。

## 关键技术事实（spike 实证，勿踩坑）

1. **参考图必须 Data URL**：`subject_reference:[{type:'character', image_file:'data:image/png;base64,...'}]`。裸 base64 与裸公网 URL（含 MiniMax 自家 OSS 回源）都会被**静默忽略**（HTTP 200 但人物无关）。
2. 生图产物 URL 仅 **24 小时**有效——server 生成后立即下载转存 `duanju/images/`。
3. `prompt` ≤1500 字符；`n`≤9；`type` 只接受 `character`。
4. 每张生成 15-30 秒；批量并发 2。
5. **拼图在前端**：分帧展示用 CSS 2×2；「下载拼图」由浏览器 canvas 现拼 2048² PNG（同源图不污染画布），server 零图片处理依赖。

## 已知边界 / 后续打磨

- 多角色镜头：分帧只携带**首个出场角色**的参考图（image-01 多参考不稳），其余角色靠 prompt 文字锚点。
- 旧缓存页面 PATCH 全量 shots 会覆盖新字段（frames/gridParts/spendLog 中 spendLog 服务端管理不受影响）——server+client 同镜像部署即无窗口期。
- 移动端窄屏：可用无溢出；chip 触控高度、tab 滚动渐隐提示待打磨（走查记录 2026-11-07）。
- APK webview 视频/上传兼容：浏览器端已验证（readyState=4/Range 206）；真机 APK 待 Phase 4 验收清单执行。
- AI 生成剧本为单轮表单式（题材/基调/想法）；多轮对话式迭代可后续增强。
- 站位快览为关键词就近解析（左/中/右/前/后/旁），是预检辅助而非精确舞台图。
