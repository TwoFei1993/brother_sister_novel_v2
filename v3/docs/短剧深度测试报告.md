### D-1（已修复）：拆解重跑产生孤儿镜头（数据一致性）
- **现象**：再次「AI 拆解」时 episodes 全量重建新 id → 旧集 id 的 shots 成孤儿（数据留存、UI 永不显示、批量也不计入）——实测中旧集 10 镜一夜「消失」只剩新集 1 镜。
- **修复**：拆解产出的集列表与现有 episodes **按 index 合并**（同 index 保留原 id，标题/梗概刷新；新 index 才新建）——抽为纯函数 `mergeEpisodes` 并补 3 项防回归单测；存量脏数据已回填归位（10 镜 · 10 图全部挂回现集）。

### D-UX1（已修复）：拆解与违审替换的保存竞态
- **现象**：改剧本未点「保存」直接「AI 拆解」→ 拆解基于编辑中文本，但「违审替换·采纳」作用于已保存文本 → split 不命中，替换静默失效。
- **修复**：`runBreakdown` 开头检测 dirty 先自动落库（剧本/审核卡/替换三者一致，同时防编辑丢失）。commit 见下。
- **测试操作注意**（非产品缺陷）：非受控 textarea 的自动化注入必须先 focus 再 blur，否则 onBlur 不触发（首测「编辑未保存」即此假象）。

### 记录在案（非阻塞）
- 违审建议粒度由模型自由裁量（本轮只替换了「血溅了一地」，未覆盖「肠子流出来」）——属生成质量调优项，可在 BREAKDOWN_SYSTEM 里收紧「original 须覆盖完整高风险句」。
- 多角色镜头仅携带首个出场角色参考图（image-01 多参考不稳，其余靠 prompt 锚点）——共识 D7 已知边界。
