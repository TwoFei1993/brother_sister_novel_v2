## 三、过程中发现并修复的问题

1. **测试污染真实数据风险**：auth 测试未隔离 DATA_DIR，P3 登录的 seedAuthor 会触碰真实 `users.jsonl` —— 已注入临时目录（`auth.test.ts`），并复查其余测试均已有隔离。
2. **空指令章被检测指令撑出「剧情指引：」裸前缀**（batch 语义回归）—— NEW_ASSETS_HINT 改为仅有指令章追加。
3. **旧 token 兼容**：P3 前签发的无 uid token 视为作者（7 天 TTL 内平滑升级，既有测试零改动全绿）。
4. **读者 UI 越权入口**：改标签按钮对读者隐藏（服务端 403 本就拦住，UI 同步收窄）；读者直击 `/m/create` 重定向阅读页。
5. **library 路由真实前缀**：library 组平铺挂 `/api`（无 `/api/library` 前缀）—— 新测试路径已对齐既有约定。

## 四、已知边界（不阻塞联测）

- 迭代聊天会话历史为内存态（刷新即清；生成的新版本是持久资产）。
- ⚡连写推进章（空指令）不触发待绑定检测（仅首章/手写章检测）；后续可改为批次结束后统一检测。
- 势力介绍暂无独立素材库 UI tab（API/复制/绑定全通），管理可暂用桌面「世界书」习惯或后续补 tab。
- 读者评论对象=上架书全部评论可见（无隐私评论概念）。
