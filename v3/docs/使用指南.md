# 使用指南

> 面向新用户的完整中文上手流程：从登录到写出第一本书。界面全部为简体中文。

## 一、登录

1. 打开站点，输入访问密码（单密码制，服务端统一校验）。
2. 登录后进入「我的书架」。首次使用书架是空的，下方「三步引导卡」会指路：
   资源中心导入 → 新建作品 → 写作台创作。

## 二、资源中心导入（推荐顺序）

路径：顶栏进入「资产库」→「资源中心」标签（或书架空态点「去资源中心」）。

推荐按以下顺序导入三件套，一步到位获得接近酒馆的写作体验：

1. **Sudachi 系预设**（如 Sudachi-Next）：社区成熟的提示词编排方案，
   决定 AI 的文风与写作流程。
2. **一张角色卡**：作品主角的设定来源（人设、开场白、对话示例）。
3. **一本世界书**：世界观设定集，关键词命中时自动注入（地名、势力、规则等）。

资源中心的三个来源说明：

| 来源 | 说明 |
| --- | --- |
| 官方内置 | 酒馆自带资源，本地复制导入，离线可用 |
| 社区直链 | GitHub 公开仓库（Sudachi-Next、社区卡合集等），服务端拉取后入库 |
| 自定义 | 任意 https 直链或本地上传，不限于清单 |

右上角「⟳ 刷新」可重新拉取资源索引；导入成功后会自动跳到对应资产标签页。
本地上传支持酒馆格式文件（角色卡 PNG/JSON、世界书 JSON、预设 JSON）。

## 三、新建作品（两种模式）

书架右上角「＋ 新建作品」，需要填：标题、模式、题材，可选绑定资源。

- **互动小说（novel）**：指令驱动、按章续写。你输入剧情方向，AI 写出下一章。
  适合小说创作。支持三种视图切换（见下节）。
- **对话写作（chat）**：酒馆式角色扮演，以角色口吻逐条对话。固定对话视图，
  没有章节与目录。

绑定资源（均可留空，稍后可在作品设置里调整）：

- **角色卡**：作品主角设定。
- **世界书**：关键词触发的世界观注入。
- **预设**：提示词编排方案（推荐绑定 Sudachi 系预设）。

题材不仅决定封面配色，也决定进入作品时应用的主题皮肤（可在设置页改为固定主题）。

## 四、写作台：三视图与指挥条

进入作品后，顶栏可切换三种视图（仅 novel 模式）：

- **💬 对话流（A）**：一问一答的流式写作视图，逐段看 AI 输出。
- **📖 沉浸阅读（B）**：默认视图，按章节阅读成稿，底部指挥条随时续写。
- **🛠️ 工作台（C）**：章节树 + 快速指令 + 历史记录的编辑工作区。

底部**指挥条**的用法：

| 控件 | 作用 |
| --- | --- |
| 指令输入框 | 剧情方向（可空）。如「兄妹进入遗迹深处…」 |
| ▶ 续写 | 按当前指令写下一章；留空则 AI 自由发挥 |
| 🎲 换一支 | 同一章重新生成一个候选版本 |
| ◀ ▶（2/3） | 多支候选间切换对比，选中即保留 |
| ⏹ 停止 | 中断生成；已生成的半段保留 |
| 继续 | 断流/停止后出现，以半成品为上下文接着写 |

TTS 听书条（阅读视图底部）支持播放/暂停/上下章、旁白声切换与 6 档语速。

## 五、资产库与提示词管理器

路径：资产库 →「预设」标签 → 点某个预设的「编辑」。

- 每行是一个提示词条目：勾选框启停、↑↓ 调整顺序、点击展开编辑内容；
  标了「系统位」的是装配占位（如主提示词、聊天历史），不可删除。
- 每行名称下方有一句**中文简介**，说明该条目是干什么的
  （如「主提示词（AI 的核心任务定义）」「文风选项（单选组之一）」）。
- 头部显示预估总 token；右上角「保存」才会落盘。

**Sudachi 预设分组说明**（打开 Sudachi 系预设时列表顶部有可展开的使用指南卡）：

1. **主提示词**：main 区，AI 的核心任务定义。
2. **COT**：思维链，先思考再写正文，【始】【末】两段需同时启用。
3. **文风单选组**：启用一条作为全文文风（轻小说/短剧式/番剧式…），其余保持停用。
4. **人称单选组**：选一条决定叙事人称。
5. **附加选项多选**：❎反XX（对抗 AI 坏习惯）与 🍈生动化 等可按需多选。
6. **操作区**：预留操作位，无需改动。

## 六、TTS 分声设置

- **全局地址**：设置页 →「TTS」→ 填 easyvoice 服务地址 → 「测试连通」。
- **作品分声**：作品内设置 → 分声绑定。每个绑定角色可指定一个声音，
  未设置的角色跟随旁白默认声；旁白默认声也可单独指定。

## 七、世界书编辑器入门

路径：资产库 →「世界书」→「编辑」。左侧条目列表，右侧表单：

- **主键**：触发关键词。最近的对话文本中出现任一主键，该条目才注入。
- **常驻条目（constant）**：开启后跳过关键词判定，每轮必定注入
  （列表里有蓝色小圆点标记）。世界观骨架建议设为常驻。
- **插入位置**：角色卡之前 / 角色卡之后 / 按深度注入（距对话末尾 N 层）。
- **顺序 order**：同时命中多条时的排序权重，数值越大越靠前。
- **二级键 + 逻辑**：对主键做二次过滤（如要求同时命中）。
- **扫描深度 / 概率 / 大小写 / 全词匹配**：留空即跟随全局设置。

改完点右上角「保存」；标题旁出现「未保存」徽标说明有改动未落盘。

## 八、旧数据迁移

如果你用过旧站：在旧站浏览器控制台执行设置页给出的导出命令
（`localStorage.getItem(...)`），把下载的 JSON 在「设置 → 旧站迁移」上传，
预览确认后逐作品迁入，书架立即可见。

## 九、界面主题

设置页 →「界面偏好」：默认「跟随作品题材」换肤；也可固定为
穿越重生 / 星际科幻 / 末世求生 / 无限流 / 玄幻修仙 / 混合暗色 六套主题之一
（即时生效，保存在本设备，刷新后保持；固定后不再随作品切换）。

## 十、常见问题（FAQ）

**生成失败 / 没有输出，按此顺序排查：**

1. **密钥**：设置 → LLM 接入，对应通道是否已配好 API Key（显示「已配置」徽标）。
2. **模型名**：设置 → LLM 接入 → 模型名是否填写且与服务商名称完全一致
   （如 MiniMax-M3）。留空时「测试连接」用探活小模型可能通过，但正式生成会失败。
3. **测试连接**：设置页点「测试连接」，看具体错误码提示；兼容端点（如 MiniMax）
   需要正确填写接口地址。
4. 以上都正常仍失败：查看服务端日志；TTS 问题同理，先「测试连通」再查 easyvoice
   服务是否在线。

**其他：**

- **预设启停改了不生效？** 提示词管理器右上角要点「保存」。
- **世界书条目没注入？** 检查条目是否被禁用、主键是否出现在最近对话、
  扫描深度是否覆盖了对话层数。
- **下拉框文字看不清？** 已全站修复为跟随主题配色；若仍遇到，刷新页面并反馈。
