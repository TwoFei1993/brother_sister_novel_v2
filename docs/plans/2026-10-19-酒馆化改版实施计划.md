# 酒馆化改版实施计划（V3）

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 按 `docs/酒馆化改版设计.md`（已评审定稿）实施 monorepo 全栈改版：酒馆式双模式小说系统。

**Architecture:** 前端组装提示词（engine/ 纯函数）+ Express 薄代理（协议转换+密钥）+ JSON 文件存储（per-work 写队列+乐观锁）。React 19 SPA 与 API 同源部署。

**Tech Stack:** pnpm workspace · server: Express4+TS+tsx+pino+zod+supertest · client: Vite+React19+Tailwind4+Zustand+react-router7+react-markdown+rehype-sanitize+DOMPurify · 测试: vitest 全栈 + Playwright E2E · token: js-tiktoken（lazy）

**硬规范（全程生效）:** 每文件 ≤300 行；每目录 ≤8 文件；全 TS 禁 any；ESM 禁 CommonJS；中文注释/UI 文案；提交信息中文或 conventional；每任务 TDD（先测后码）小步提交。设计文档 `docs/酒馆化改版设计.md` 是唯一权威，冲突以它为准。
