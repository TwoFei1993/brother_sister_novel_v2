## 二、缺陷清单

### 已修复（5 项，均 ≤30 行 + 回归测试）

**D1【低】错误提示条被作品设置面板遮挡**
- 复现：作品设置面板（fixed z-50）打开时触发生成错误 → 顶部提示条被面板覆盖，「知道了」按钮无法点击（pointer 拦截）
- 根因：提示条为文档流内元素，z 层级低于面板
- 处置：提示条改 fixed 顶部浮层 + z-[60]（WorkPage.tsx / ChatWorkspace.tsx 两处同步）

**D2【中】C 工作台「指令历史」在 novel 模式永远为空**
- 复现：novel 作品任意带指令续写后，C 视图指令历史恒显示「还没有发送过指令」
- 根因：DirectiveHistory 按 `role==='user'` 过滤，而 novel 的指令存在章节消息 `directive` 元数据、不落独立 user 消息
- 处置：取数改为 `role==='user' || directive 非空`，展示/复填取 `directive ?? content`；导出 `directiveList` 纯函数 + 3 项回归用例（DirectiveHistory-list.test.ts）

**D4【中】chat 回复开头残留提示词复读片段**
- 复现：真实 MiniMax 对话，回复开头出现 `</Aniplex>只写角色行为语言…</Aniplex>`（模型复读提示词包裹段）
- 根因：sanitizeOutput 的自定义标签剥离只处理成对 `<Tag>…</Tag>` 与未闭合 `<Tag>…`，孤立闭合标签 `</Tag>` 开头的形态不命中
- 处置：新增开头孤立闭合标签剥离（剥到同名闭合标签；剥后过短保护性放弃，正文中间出现不误伤）；3 项回归用例。历史污染消息属修复前数据不追溯

**D5【中】向导世界书「势力」条目提取错误**
- 复现：粘贴含「……血衣楼为天下第一刺客组织，总部位置成谜。」的大纲 → 世界书「势力」条目 content 仅「总部位置成谜。」且关键词错误
- 根因：factions 第二组正则 `(?:势力|阵营|组织|家族|帝国)[：:、，]` 允许句中「组织，」命中，捕获后半句而非「势力设定：」字段段
- 处置：锚定行首 + 编号类短前缀（`(?:[（(]?[\d一二三四五六七八九十]{1,3}[）)]?[、.．：:]|\S{0,4}?)`）+ 后缀白名单（设定/分布/简介）；3 项回归用例（编号行/行首/正文误伤例）

**D6【中】B 视图刷新后顶部「加载更早章节」无法触发**
- 复现：>50 章作品刷新进入 B 视图（首屏即窗口顶部），向上滚轮无 scroll 事件（scrollTop 已为 0），「继续向上滚动加载更早章节」提示永远无法满足，须先下滚再上滚
- 根因：加载触发仅挂在 onscroll；scrollTop=0 时向上滚动不产生事件
- 处置：挂载及 hasMore 变化时若已在顶部主动补触发一次 onNeedOlder（ReadingView.tsx useEffect）

### 记录不修（4 项）

**D3【中】「删除中间章节」前后端断层**
- 服务端 `DELETE /api/works/:id/messages/:mid` 已实现（含测试），前端 A/B/C 视图均无入口，用户无法触达
- 不修理由：删除中间章涉及后续章节编号重排、候选/指令元数据级联与确认交互设计，超出「≤30 行小修」边界，需产品交互方案先行

**D7【低】chat 模式 meta-only 占位以角色名义入库**
- 复现：自动连播中某轮输出仅有思考/元信息 → 对话流出现一条以「哥哥」为名、内容为「（本章只剩元信息，没有正文——建议 🎲 重新生成本章或切换候选。）」的消息
- 说明：novel 流对 meta-only 不入库并自动重试；chat 的 finalizeChatGeneration 无该拦截，占位经 presentable 注入后入库。该占位为「有引导的降级」（气泡带重roll按钮），但以角色名义出现不优雅；彻底修复涉及连播轮换状态机锚点调整，记录待议

**D8【低】作品页 h1 章数为 stats 快照、生成后滞后**
- 复现：52 章作品 h1 显示「共 50 章」，生成完成后仍短暂滞后（h1 读 work.stats，messages 实时）
- 说明：显示层快照语义，不造成数据问题；如需精确可改为本地 chapters.length 派生

**D9【微瑕】向导两处体验毛边**
- 卡片描述将「反向 prompt：无」原样拼入（应为「无」时省略）；向导页刷新后粘贴内容丢失（未持久化草稿）

### 观察项（非缺陷）

- 「⚡ 连写」无确认弹窗，一次点击直奔「目标章节数」默认 50（设置面板可改）。行为与按钮说明文档一致，但对新用户有「连写 3 章」的直觉落差，可考虑首次弹确认
- MiniMax-M3 偶发整段重复（历史消息中大段文本重复 3 次），为模型采样行为，非客户端 bug；净化管道已拦截其泄漏形态
